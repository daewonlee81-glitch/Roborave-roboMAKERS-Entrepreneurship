# WindLight — Script Practice App (윈드라이트 대본 연습 앱)

Presentation practice tool for **WindLight**, Team RoboMakers' smart bike-helmet light
for the RoboRAVE Taiwan Open 2026 Entrepreneurship Challenge.

로보레이브 대만 오픈 2026 기업가정신 발표 대본을 연습하는 앱입니다.

## 바로 사용하기

**https://daewonlee81-glitch.github.io/Roborave-roboMAKERS-Entrepreneurship/windlight/script-coach/**

- PC의 **Chrome** 또는 **Edge**로 여세요. Edge를 쓰면 AI 목소리가 더 자연스럽습니다.
- 처음 시작할 때 마이크 사용을 **허용**해 주세요.

## 기능

| 기능 | 설명 |
|---|---|
| 음성 확인 | 마이크로 영어 대사를 듣고, 맞게 말한 단어는 초록, 빠진 단어는 빨강으로 보여 줍니다. |
| 3초 카운트다운 | ▶ 연습 시작을 누르면 3 → 2 → 1 → 시작! |
| 다음 대사 | **다음 ▶** 버튼이나 키보드 → 키 (← 키는 이전 대사) |
| 혼자 연습 | 내 역할(A 박라엘 · B 강지석 · C 박정현)을 고르면 다른 사람 대사는 AI 목소리가 대신 읽어 줍니다. |
| 녹음 | 연습 전체를 녹음하고, 결과 표에서 대사 한 줄씩 다시 들을 수 있습니다. **파일로 저장**으로 내려받으세요. |
| 결과 | 줄별 점수, 걸린 시간(목표 3분), 자주 빠진 단어 |

녹음과 점수는 브라우저 안에만 있고 어디에도 전송되지 않습니다. 새로고침하면 사라지니 필요한 녹음은 저장해 두세요.
(음성 인식은 브라우저의 기능을 사용하므로, Chrome·Edge가 인식을 위해 음성을 자체 서버로 보낼 수 있습니다.)
